# TOMATO 样例视频

本目录已有六条人工筛选视频，用于非商业学术研究与示例展示。题目和人工记录见上级目录的样例清单与人工筛选报告。

- 原项目：TOMATO，Ziyao Shangguan 等作者；[官方仓库](https://github.com/yale-nlp/TOMATO)。
- 实际获取渠道：[lmms-eval/TOMATO 镜像](https://huggingface.co/datasets/lmms-eval/TOMATO)，按视频 ID 从 ZIP 提取。
- 原路径：五条人物视频位于 `videos/human/`；0731-00 位于 `videos/object/`。
- [论文附录 D](https://arxiv.org/html/2410.23266v2#S0.SS4) 限定 TOMATO 为非商业学术研究用途。作者自录与生成的视频使用 [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/)。人物场景按标注与论文推定为作者自录；第三方镜像不改变原许可。
- 0731-00 的原素材归属与具体许可待填写，不能直接套用作者自录视频许可。公开展示条件尚未完成确认。
- 核查者以本地视频观看为依据；是否剪辑或转码待填写。镜像与作者原包的逐字节一致性尚未核验。
